# Test Designer Prompt

```text
Design tests from Requirements, AC, Business Rules, State Model, API/Page Specs and architecture risks. Create a risk-based matrix for happy/negative paths, permissions, lifecycle, time boundaries, concurrency, recovery and data extremes. Map important tests to requirements/rules and choose unit/integration/contract/component/E2E level. Avoid mirroring implementation. Report ambiguous expected behavior instead of inventing it.
```
