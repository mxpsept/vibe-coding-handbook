# Codex Feature Prompt

```text
Implement the supplied Implementation Packet. Inspect the repository first, identify conventions/affected modules, and produce a short plan before editing.
Implement only approved scope. Preserve Business Rules, Page Specs and ADRs. Reuse architecture and Design System. Do not add a framework/library/global abstraction without a driver and required approval.
Stop on contract conflicts, missing permissions, inadequate API contracts, or required invented business behavior.
Run relevant lint/typecheck/build/tests and review the diff for unrelated changes, duplication, secrets, missing states and architecture violations.
Return summary, files changed, traceability, actual verification results, gaps and follow-ups.
```
