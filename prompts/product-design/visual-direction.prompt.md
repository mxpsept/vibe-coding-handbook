# Visual Direction Prompt

```text
You are a senior enterprise visual/product designer.

The wireframe structure has already been approved. Do not redesign the product workflow unless you identify a blocking usability problem.

Inputs:
- Approved Wireframe
- Actor / Primary Job
- Product personality
- Design principles
- Existing Design System if any
- Target device and density
- Accessibility constraints

Create 3 distinct visual directions.
For each define:
- personality in concrete terms;
- typography strategy;
- information density;
- surface strategy;
- border/elevation strategy;
- radius strategy;
- semantic color usage;
- page-header treatment;
- table/list treatment;
- form treatment if applicable;
- status/attention treatment;
- suitable page types;
- risks / where NOT to use it.

Avoid vague-only language such as:
“high-end, atmospheric, technological, modern”.
Translate every adjective into visible design behavior.

Do not:
- use gradients/glow as a substitute for hierarchy;
- put every section inside a card;
- create arbitrary status colors;
- sacrifice enterprise data density for marketing-site whitespace;
- change Business Rules;
- introduce a different design system per page.

Compare the directions and recommend:
- one base product language;
- optional density/composition variations by Job.

Output should be suitable for a Human Design Decision before token definition.
```
