# Minimum AI Project Kickoff Kit

不需要在开发前写几十份文档。一个中等复杂度企业 Feature/项目，至少确认下面这些事实。

## Product
- [ ] Problem / target user 清楚
- [ ] Success / outcome 清楚
- [ ] Non-goals 清楚
- [ ] Domain glossary 已开始维护

## Behavior
- [ ] Critical workflow 可描述
- [ ] Acceptance Criteria 可验证
- [ ] Critical Business Rules 有 Owner
- [ ] Lifecycle/State 没有明显歧义
- [ ] Permission/data scope 有基本定义

## UX
- [ ] Critical User Flow 已确认
- [ ] UI direction 不完全由 Coding Agent 临场发挥
- [ ] Page critical states 有定义

## Architecture
- [ ] Repository/module owner 清楚
- [ ] API/data boundary 清楚
- [ ] 重要 quality/security constraints 已识别
- [ ] 新技术选择有 Driver，而不是“AI 推荐”

## Agent
- [ ] Repository Instructions 可用
- [ ] Task 有 Scope / Non-goals
- [ ] Stop Conditions 明确
- [ ] Agent Git/外部系统权限明确

## Verification
- [ ] 知道怎样证明 AC
- [ ] Critical negative/permission/state path 被考虑
- [ ] Build/test commands 可执行

## Production
- [ ] 关键失败模式可以观察
- [ ] migration/integration risk 被识别
- [ ] release/rollback owner 明确（若进入生产）

## Decision

如果以上缺项很多，不代表不能开始 Discovery/Prototype；但不要把探索性 AI 输出误认为 Production-ready implementation。
