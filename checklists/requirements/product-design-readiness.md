# Gate 2 — Requirements → Product Design Readiness

## Language
- [ ] Core Glossary defined
- [ ] Completion / Closure 等易混概念已拆分
- [ ] 未定义关键术语已列为 SPEC_GAP

## Scope
- [ ] Product Outcome 清楚
- [ ] MVP 是业务闭环而非页面数量
- [ ] In Scope / Out of Scope / Future Candidate 分离
- [ ] 新增能力有 Evidence / Job 理由

## Business Rules
- [ ] 核心 Rule 有稳定 ID
- [ ] Candidate / Approved / TBD 状态明确
- [ ] UI 和技术实现没有冒充 Business Rule
- [ ] AI 未静默补齐未知规则

## Lifecycle
- [ ] 核心对象状态定义清楚
- [ ] Lifecycle 与 Attention / Risk / Progress 分离
- [ ] 关键 Transition 有 Actor / Preconditions / Effects
- [ ] Terminal States 明确
- [ ] Forbidden transitions 已识别

## Functional Specification
- [ ] 核心 Job 有 User Story / Requirement 承接
- [ ] 复杂跨角色流程有 Use Case
- [ ] 权限与错误路径被考虑
- [ ] Requirement 不只是 CRUD/menu list

## Acceptance
- [ ] Implementation-ready Story 有 AC
- [ ] AC 包含关键 Negative Case
- [ ] AC 可以被 Test Agent 验证
- [ ] Blocked AC 明确关联 SPEC_GAP

## NFR
- [ ] Security / Audit / Integrity 已评估
- [ ] Performance / Availability 没有虚构数字
- [ ] TBD 有验证方法和 Owner

## Traceability
- [ ] Evidence → Finding → Requirement 可追踪
- [ ] Requirement → Rule / AC 可追踪
- [ ] Orphan Requirement 已处理
- [ ] 高价值 Finding 未被无意遗漏

## Product Design Handoff
- [ ] Designer 能知道主要角色和 Jobs
- [ ] Designer 能知道主要 Use Cases
- [ ] Designer 能知道 State / Attention 语义
- [ ] Designer 能知道哪些 Business Rule 不可被 UI 改写
- [ ] UI 方案尚未被 Requirements 过早锁死

## Decision
- [ ] PASS — Enter Product Design
- [ ] PASS WITH GAPS — Non-blocking gaps remain
- [ ] HOLD — Resolve specification gaps
- [ ] RETURN TO DISCOVERY
