## How to Use Resources

不要这样：

```text
看了 20 篇 AI Coding 文章
→ 收集 50 个 Prompt
→ 项目仍没有 Spec / Tests / Architecture Boundary
```

建议：

```text
遇到工程问题
→ Handbook 找方法
→ Primary Source 学工具/标准
→ 在小案例验证
→ 固化为项目 Artifact/Rule/Automation
```

外部资料中的观点只有经过团队验证和决策后，才成为 Project Truth。
