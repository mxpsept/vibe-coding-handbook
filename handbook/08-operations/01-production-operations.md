# Stage 08 — Production Operations

Observe availability, latency, errors, saturation, dependencies and failures of critical business actions.

Incident loop: `Detect → Triage → Mitigate → Recover → Verify → Root cause → Corrective action → update tests/runbooks/architecture`.

AI can accelerate log analysis and hypotheses, but must distinguish evidence from inference. Maintain reviewed runbooks for deployment, DB/auth/dependency outages, migration failures, high errors and data correction.

Never let an agent improvise destructive production commands from incomplete context.
