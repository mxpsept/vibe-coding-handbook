# Role-based Learning Paths

## Developer / Coding Agent User

优先顺序：

```text
START-HERE
→ Requirements basics
→ Architecture boundaries
→ Implementation
→ Testing
→ Brownfield
→ Debugging
→ Agent Governance
→ Code Review
```

目标：从“让 AI 写代码”升级为“给 AI 一个可验证工程任务”。

## Tech Lead / Architect

```text
Requirements / State Model
→ Architecture
→ ADR
→ Agent Governance
→ Refactoring
→ Migration
→ Multi-Agent
→ Security / Performance
→ Technical Debt
→ Governance
```

目标：建立 Agent 不容易破坏的边界。

## Product Manager / BA

```text
Discovery
→ Requirements
→ Business Rules
→ State / Permission
→ Product Design
→ Acceptance Criteria
→ Metrics / Feedback
```

目标：让 AI 获得稳定业务语义，而不是只获得一句需求描述。

## UI/UX Designer

```text
Discovery
→ Product Design
→ User Flow
→ Wireframe alternatives
→ Design System
→ Page Spec / UI State Matrix
→ UX Review
```

目标：避免 AI Default Dashboard 和 Screenshot-only implementation。

## QA / Quality Engineer

```text
Requirements / AC
→ State / Permission
→ Testing
→ Debugging
→ Code Review
→ Production Readiness
→ Incident Feedback
```

目标：从“执行测试用例”升级为风险和 Evidence 设计。

## DevOps / SRE

```text
Delivery
→ Operations
→ Security
→ Performance
→ Incident Response
→ Observability
→ Data/Integration failure modes
```

目标：让 Agent 参与运维但保持受控生产权限。

## Engineering Manager / Enterprise Leader

```text
Team Adoption
→ Metrics
→ Governance
→ Maturity Model
→ Security / Production Readiness
```

目标：衡量 outcome，设计权限和治理，而不是只采购 AI License。
